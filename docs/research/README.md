# TAXLANE Research Notes

Research notes in this directory should be cited and should distinguish:

- primary-source facts,
- secondary-source summaries,
- interpretation,
- reform hypotheses,
- open questions.

## Showcase Research Path

For the current showable research/readiness state, start with
`docs/reading/taxlane-showcase-readiness-summary.md`. The research notes support
the public-policy thesis and source trail, but they do not by themselves make
solver inputs, rates, savings, public rate cards, department-cut instructions,
technology-savings claims, or balanced-budget outputs ready.

The first research pass should cover TAXLANE history, current revenue and
appropriation mechanics, and the tradeoffs of program-linked tax lanes.

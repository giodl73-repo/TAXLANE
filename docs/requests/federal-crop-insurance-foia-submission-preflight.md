# FCIC FY2024 Cohort-Disposition FOIA Submission Preflight

Status: **blocked; owner completion and explicit submission authorization required**

No request should be sent until every required item below is complete.

## Owner and authority

- [ ] Requester name and organization/individual status completed.
- [ ] Email, telephone, and mailing contact completed.
- [ ] Owner has reviewed the exact frozen request text.
- [ ] Owner explicitly authorizes external submission.
- [ ] Exactly one channel is selected: RMA email or USDA portal, not both.
- [ ] No expedited-processing claim is included unless separately supported and
  approved.

## Fees

- [ ] Requester fee category is confirmed from requester facts.
- [ ] Exact fee ceiling is approved.
- [ ] Fee-waiver request is either omitted or supported with a written factual
  public-interest and noncommercial justification.
- [ ] The request requires consultation before exceeding the authorized ceiling.

## Scope and privacy

- [ ] Scope remains the 326-policy FY2024/RY2022 COM-23-001 cohort.
- [ ] Date range starts April 1, 2023 and ends on the agency search date.
- [ ] Existing records only; no new analysis, recovery-rate calculation,
  pseudonym creation, or new table is demanded.
- [ ] Direct producer, AIP, crop, policy, claim, farm, and location identifiers
  remain excluded.
- [ ] Existing deidentified, statistical, aggregate, and segregable fallbacks
  remain accepted.
- [ ] Native electronic format remains preferred.

## Freeze and custody

- [ ] Replace every bracketed placeholder.
- [ ] Save the exact outbound body and attachments.
- [ ] Compute and record SHA-256 checksums before sending.
- [ ] Record submission channel, timestamp, destination, and message or portal
  confirmation.
- [ ] Create the first response-intake record with lifecycle state `submitted`.

Completing this checklist does not itself authorize submission or commit fees.

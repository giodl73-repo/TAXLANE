# REV Level-5 administration implementation ceiling

Treasury records $77 million of FY2019 IRS funding to implement the much
broader 2017 tax law. GAO separately reports that, after policy decisions,
annual withholding-table updates follow a routine process. Neither source
scores this proposal's marginal cost.

Using the $77 million only as a deliberately conservative agency-side ceiling
adds approximately 0.001 point to the Level-4 timing sensitivity: +10.923
points centrally and approximately +10.160 to +11.854 across the behavioral
range. Private compliance burden and the true marginal IRS cost remain null,
so this is not an administration-adjusted or assigned rate.

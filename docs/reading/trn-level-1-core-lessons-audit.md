# TRN Level-1 CORE lessons audit

H.R. 2247 reveals a shared modeling distinction that the existing CORE stack
does not yet express cleanly. It is a real, officially scored, cost-only service
modernization candidate. It is not a lower-cost proposal, a receipt instrument,
or evidence of savings.

That means the next shared interface should type the candidate before deciding
which solver and release gates apply. It should also distinguish an
appropriation perimeter from a fund or receipt source, scope floors to the
candidate, allow reviewed non-applicability, and reconcile the candidate's
evidence in one dossier.

The audit therefore recommends discovery of `CORE-M — Candidate Dossier and
Typed Release Profiles`. CORE-M is not started or complete. TRN source work can
continue, but H.R. 2247 cannot be relabeled as a savings or rate candidate.

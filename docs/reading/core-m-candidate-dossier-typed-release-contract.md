# CORE-M candidate dossiers and typed release profiles

CORE-M is the shared bridge between admitting a real candidate and deciding
which outputs could ever be meaningful for it. It prevents a cost-only service
modernization from being treated as a savings proposal, an appropriation from
being treated as a named fund, and a lane-wide floor from being imposed on an
unrelated candidate without an applicability review.

The implementation validates six candidate profiles and three gate states. It
is exercised against TRN cost-only modernization, PAY non-additive controls,
REV receipt-rate prerequisites, and NET endogenous effects.

CORE-M does not select a candidate or open an F stage. Those remain lane-local
decisions after a dossier is populated with real evidence.

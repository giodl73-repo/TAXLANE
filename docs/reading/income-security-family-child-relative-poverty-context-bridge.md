# Income-security/family child relative poverty context bridge

This packet explains
`data/derived/breadth_benchmark_matrix/income_security_family_child_relative_poverty_context_bridge.v1.draft.json`.

Pulse 196 reuses the already source-custodied OECD child relative-poverty panel
for the income-security/family lane. The source is
`SRC-OECD-IDD-AGE-POVERTY-PANELS`; the child raw file is
`data/raw/oecd/SRC-OECD-IDD-AGE-POVERTY-PANELS/2026-07-15/oecd-idd-child-poverty-2020-2021.csv`,
with 2,546 bytes and SHA-256
`3ec2eaa896abf855ffa75067b99aaac340fbb9061a4f8e0b3f70333c77b33d08`.

The context value carried forward for the United States is 13.99 percent in
2021 for children under 18 living in households below 50 percent of national
median equivalised disposable income. That is international relative-poverty
context only. It is not an absolute deprivation threshold and does not identify
family-policy causality by itself.

This bridge does not close the domestic Census child poverty and income-unit
gate. It leaves Census custody, domestic income definition, deep poverty or
near-poverty context, same-year benefit-package linkage, and reviewed floor
threshold selection open.

This bridge is not Census domestic child poverty custody, not domestic
income-unit context, not child-poverty floor values, not material-hardship floor
values, not a benefit package model, not a take-up model, not
federal/state/local translation, not pass/fail findings, not target-cost
selection, not gross savings, not net savings, not solver input, not rate
calculation, not a public rate card, not a department-cut instruction, not a
technology-savings claim, and not a balanced-budget claim.

Short validator phrases: international child relative-poverty context only; not
Census domestic child poverty custody; not solver input; not a balanced-budget
claim.

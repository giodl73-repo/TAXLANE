# Education Workforce Graduation Floor Value Packet

Machine record:
`data/derived/breadth_benchmark_matrix/education_workforce_graduation_floor_value_packet.v1.draft.json`

This packet converts one education/workforce floor from context-only to a draft
threshold and baseline floor value. It uses the K-12 outcome baseline record
`data/derived/breadth_benchmark_matrix/k12_outcome_baseline.naep2024-acgr2021-22.v1.draft.json`.

The selected floor is completion/persistence. The draft threshold rationale is
no regression from the national public high-school four-year adjusted cohort
graduation rate. The selected threshold and baseline are both 87.0 percent for
school year 2021-22.

Equity context is retained from the same baseline: American Indian/Alaska Native
74.0 percent, Asian/Pacific Islander 94.0 percent, Black 81.0 percent, Hispanic
83.0 percent, White 90.0 percent, students with disabilities 71.0 percent,
English learners 72.0 percent, economically disadvantaged students 81.0 percent,
and enrolled homeless students 68.0 percent.

Boundary: this is a draft no-regression education/workforce graduation floor
threshold and baseline value packet only. Policy and stress values remain null.
It is not federal/state/local translation, not postsecondary completion, not
WIOA placement, not policy impact, not pass/fail evidence, not lower-cost
scenario admissibility, not target cost, not solver input, not rate calculation,
not savings, not a technology-savings claim, and not a balanced-budget claim.

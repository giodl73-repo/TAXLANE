## What Changed

rows with concrete program or project signals from rows that are still mostly
context or source-readiness blockers.

## Current Pattern

The strongest near-term probes are payment-integrity scorecards, defense
procurement/audit controls, disaster mitigation project records, and Treasury
debt context. Health remains the largest pressure surface, but both health
levers are still blocked before scoring because the service-level CMS/HHS price,
workflow, quality, access, and case-mix extracts are not attached yet.

## Boundary

This rollup is an implementation status map only. It is not a savings estimate,
not a finding of waste, and not a public performance claim.

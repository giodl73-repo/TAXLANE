# REV Level-2 zero-admitted-spending reconciliation

The Level-1 +2.760-point schedule assumed a $500 billion annual spending
correction. The completed fiscal conversion admits no spending correction, so
that schedule is superseded for the active package.

With the full $813.727 billion FY2026 primary deficit left to finance, the same
$113.668 billion-per-point linear proxy yields +7.159 points. Applied uniformly
to the current 10, 12, 22, 24, 32, 35, and 37 percent brackets, the mechanical
schedule is 17.159, 19.159, 29.159, 31.159, 39.159, 42.159, and 44.159 percent.
The static and older option anchors imply +7.000 and +7.655 points.

These figures are scoring targets, not assigned rates. A proper rate still
requires current-law nonlinear tax-unit scoring and the remaining gates.

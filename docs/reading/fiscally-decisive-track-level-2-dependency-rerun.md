# Fiscally decisive track Level-2 dependency rerun

HLT, OAS, PAY, NET, and DEF have each advanced through a second bounded level.
The rerun makes their remaining dependencies precise rather than manufacturing
package values.

The main results are structural: HLT and DEF need current-law rescoring and
outcome-floor completion; OAS needs a 2026 Trustees/cohort/distribution bridge;
PAY needs a specific causal control and returned-fund chain; NET needs the full
debt, maturity, rate, timing, and iteration path. None may yet enter an additive
package total.

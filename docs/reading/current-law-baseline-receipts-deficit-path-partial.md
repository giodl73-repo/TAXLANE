# Current-law baseline receipts and deficit path partial

Record path: `data/derived/breadth_benchmark_matrix/current_law_baseline_receipts_deficit_path_partial.v1.draft.json`.

This packet publishes a partial official current-law receipts and deficit path for FY2025 through FY2031 from existing local OMB custody.

FY2025 through FY2031 total receipts come from OMB Historical Table 2.1. FY2025 through FY2031 total outlays come from the Pulse 122 official OMB outlay path. The deficit is calculated as total outlays minus total receipts, using positive deficit as financing need.

No external request was submitted and no agency or person was contacted in this pulse.

FY2032 through FY2035 remain null because no local official captured annual values cover those years. Missing values remain null and interpolation is prohibited.

This is a partial receipts and deficit path only. It is not a complete ten-year baseline path, not a fund split, not general-fund path values, not trust-fund path values, not health component path values, not net-interest/debt path values, not solver inputs, not a solver run, not target-cost selection, not rate calculation, not a public rate card, not a tax proposal, not a savings estimate, not a waste finding, not a fraud finding, not a department-cut instruction, not a technology-savings claim, and not a balanced-budget claim.

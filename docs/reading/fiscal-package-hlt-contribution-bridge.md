# Fiscal-package HLT contribution bridge

The Medicare Advantage candidate does not change the FY2026 rate case because
it begins in 2027. The guarded REV uplift therefore remains 2.760 points.

Across FY2027-FY2034, the HLT scale proxy averages $62.131 billion per year,
about 12.426 percent of the assumed $500 billion annual target. Even if it later
passes mitigation and formal scoring, the remaining mechanical requirement
would average about $437.869 billion per year. For now its admitted contribution
is null because the beneficiary floors rejected the candidate.

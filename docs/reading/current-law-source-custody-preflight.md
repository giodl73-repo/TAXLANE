# Current-law source-custody preflight

Record:
`data/derived/breadth_benchmark_matrix/current_law_source_custody_preflight.v1.draft.json`

This packet defines what must exist before current-law annual path values can be
entered. It does not publish source custody and it does not publish current-law path values.

No external request was submitted. No source values were captured.

Each required path needs raw bytes, metadata, retrieval date, byte count, and
SHA-256 custody, plus extraction-method, component-mapping, annual-coverage, and
review fields. Missing values remain null until those fields are present.

Rows covered:

- full 17-row FY2025 ledger
- baseline plus ten-year unified horizon
- OASDI annual fund path
- Medicare HI annual fund path
- transportation trust-fund annual values
- general fund annual path
- health fiscal current-law path
- net interest current-law path

This is not source custody, not current-law path values, not a solver run, not target-cost selection, not rate calculation, not a public rate card, not a tax proposal, not a savings estimate, not a waste finding, not a fraud finding, not a department-cut instruction, not a technology-savings claim, and not a balanced-budget claim.

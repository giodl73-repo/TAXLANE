# Payment Integrity Methodology Fields

Machine rows:
`data/derived/efficiency_pressure/extracts/payment_integrity_methodology_fields_q4_2025.jsonl`

This packet expands the methodology plans into field-level checklist rows. Each
selected program has eight open fields that must be source-cited before the
methodology blocker can close.

## Field Groups

The common fields are sample design, universe, estimation method, exclusions,
sample period, and payment-type split.

Program-specific fields handle the interpretation risk:

- Part D: state-data dependency and overpayment versus recoverable amount basis.
- VA PLTSS: documentation standard and documentation defect versus recoverable overpayment basis.
- Federal Crop Insurance: agency-process-error definition and recoverable savings basis.
- Medicaid: state rotation/weighting treatment and improper-payment versus fraud/waste basis.

## Boundary

Every row is still open. These rows are not evidence that waste occurred and do
not estimate recoverable savings.

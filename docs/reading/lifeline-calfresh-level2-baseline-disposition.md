# The data are real; the candidate effect is not yet observable

California began its expanded CalFresh work and community-engagement rules on
June 1, 2026. The current CDSS dashboard stops its operational series in May
and its error series in February, so those values are preimplementation floors.

| Comparison measure | Value |
|---|---:|
| CalFresh households | 3,107,208 |
| CalFresh people | 5,166,532 |
| Applications received | 161,045 |
| Applications denied | 60,469 |
| Procedural denials | 43,910 (72.61% of denials) |
| Thirty-day timeliness | 98.78% |
| Expedited timeliness | 96.52% |

The latest statewide churn is 2020 Q4 and therefore stale. FY2025-26 records
show 44,504 CalFresh appeals filed and 10,434 hearings held, but these are
separate aggregate flows spanning every CalFresh issue—not a candidate cohort.

The comparison baseline is complete. Candidate Level 2 remains held until at
least one full recertification cycle supplies H.R. 1-coded exposure, exemption,
waiver, access, accuracy, churn, notice, appeal, adequacy, distribution, county-
capacity, and implementation-cost evidence.

ISF does not reopen. The admitted reduction remains zero, and the $813.727B
target and 21/23/33/35/43/46/48 schedule remain unchanged.

# Public Rate-Card V2 Contract

Machine record:
`data/derived/breadth_benchmark_matrix/public_rate_card_v2_contract.v1.draft.json`.

This is a public rate-card v2 contract, not a published public rate card,
statutory-rate proposal, tax proposal, effective-rate publication, savings
estimate, waste finding, fraud finding, department-cut instruction,
technology-savings claim, or balanced-budget claim.

The contract makes "not calculated" and "blocked" first-class public outcomes.
Missing values remain null and blocked gates remain false. Public cards must
display not calculated or blocked instead of filling a zero.

Every future card must include current-law cost, current-law receipts and fund
treatment, target cost if valid, assigned base, effective rate if valid,
all-receipt funding share, residual general-fund requirement share, burden,
distribution by income, why the rate changed, outcome floors,
technology-transition status, overspending-risk classification, evidence grade,
blockers, and public-claim status.

Avoid statutory-rate language unless the rate-publication gate, role review,
public-language review, assigned-base model, incidence model, distribution
model, behavior model, administration model, and interaction scoring all pass.

All published public-rate-card, statutory-rate, effective-rate, funding-share,
target-cost, savings-estimate, and department-cut outputs remain null.

Every claim boolean remains false.

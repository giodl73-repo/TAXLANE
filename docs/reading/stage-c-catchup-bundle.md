# Four-Lane Stage-C Catch-Up Bundle

Transportation is already beyond stage C at TRN-E. This bundle completes
bounded HLT-B and EDU-B accounting, opens and closes HLT-C and EDU-C candidate
screens, and introduces Social Security as `OAS-A -> OAS-B -> OAS-C`.

OAS-A uses the existing combined OASDI current-law path, source-status rollup,
taxable-payroll context, receipt-yield boundary, and floor definitions. OAS-B
maps separate OASI and DI components, the combined non-additive OASDI view,
dedicated receipts, outlays, interest, reimbursements, and transfers. OAS-C
screens taxable-base, benefit-formula, and fund-allocation candidate families.
No Social Security reform is admitted.

The work exposed CORE-K: fiscal, calendar, and tax-year values require explicit
bridges; target horizons cannot exceed source support; composites cannot be
added to their components; and transfers must remain explicit.

HLT-C, EDU-C, and OAS-C are complete as bounded candidate screens with no
reform admitted. That is not numeric completion, output readiness, a solver
input, a rate calculation, savings, or permission to start their D stages.

# TRN-A Transportation Baseline and Source Spine

Machine record:
`data/derived/breadth_benchmark_matrix/trn_a_transportation_baseline_source_spine.v1.draft.json`.

TRN-A is complete. It consolidates the official FY2025-FY2031 OMB Function
400 net-outlay baseline, separate Highway and Airport and Airway trust-fund
context, final FY2025 Treasury anchors, FY2032-FY2035 CBO balance-only context,
the OMB/CBO overlap diagnostic, and the roadway-safety service anchor.

The source spine deliberately leaves FY2032-FY2035 Function 400 and named-fund
income/outgo values null. CBO balance projections are not stitched onto OMB
income/outgo rows. Those are accounting and source-bridge requirements for
CORE-H and TRN-B, not permission to fabricate a continuous path.

TRN-A therefore provides the evidence map and bounded baseline needed to
finalize CORE-H. It does not publish a lane solver path, reform score, target
cost, rate, savings estimate, or balanced-budget result.

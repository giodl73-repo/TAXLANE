# Income Security Family Child Poverty Floor Value Packet

Machine record:
`data/derived/breadth_benchmark_matrix/income_security_family_child_poverty_floor_value_packet.v1.draft.json`

This packet converts one income-security/family floor from context-only to a
draft threshold and baseline floor value. It uses the Census child poverty and
income capture record
`data/derived/breadth_benchmark_matrix/income_security_family_census_child_poverty_income_capture_gap.v1.draft.json`.

The selected floor is child poverty. The draft threshold rationale is no
regression from the 2024 official poverty rate for people under 18. The selected
threshold and baseline are both 14.3 percent. The baseline population is 72.550
million children, with 10.350 million below official poverty and a 0.6
percentage-point margin of error.

Supporting context from the same Census source includes under-18 SPM poverty at
13.4 percent, the three-year United States under-18 official poverty rate at
14.8 percent, and the three-year United States under-18 SPM poverty rate at
13.1 percent.

Boundary: this is a draft no-regression income-security/family child-poverty
floor threshold and baseline value packet only. Policy and stress values remain
null. It is not a benefit-package model, not take-up, not childcare access, not
nutrition handoff, not policy impact, not pass/fail evidence, not lower-cost
scenario admissibility, not target cost, not solver input, not rate calculation,
not savings, not a technology-savings claim, and not a balanced-budget claim.

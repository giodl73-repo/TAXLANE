# Seven owner/outcome lane execution frontier

The seven remaining owner/outcome lanes are no longer one undifferentiated
queue. AGR, SEE, EDU, and DIS have operating programs whose public owner data
can improve service, distribution, and delivery assessments now. VET, JUS,
and TRN first need legal or ownership triggers before candidate effects can be
observed.

## Result

| Rank | Lane | Active evidence position |
|---:|---|---|
| 1 | AGR | operating program, public administrative evidence, defined but pre-2025 scored option |
| 2 | SEE | operating grant program and current program context, but small unmatched reduction option |
| 3 | EDU | operating benefit program with useful owner data and substantial later-law interactions |
| 4 | DIS | operating program, but the selected fiscal option dates to 2018 and needs replacement or refresh |
| 5 | VET | owner-aligned and scored, but enactment, funding, and implementation have not occurred |
| 6 | JUS | owner-aligned capacity baseline, but the proposal is unenacted and increases spending |
| 7 | TRN | unenacted conditional cost proposal with an unresolved aviation-owner mismatch |

AGR is selected for a bounded public-evidence audit. The audit will reconcile
the crop-insurance program after the 2025 reconciliation changes and test what
official sources can establish about producer distribution, participation,
insurer returns, disaster substitution, resilience, and food security.

This selection is not a recommendation to reduce crop-insurance support. It
does not reuse the December 2024 score as current law, admit $4.9 billion for
FY2026, or change TAXLANE's spending, allocation, NET, REV, or rate results.

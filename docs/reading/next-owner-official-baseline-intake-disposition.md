## The interoperability result

All four outputs use the same fourteen-section Taxlane envelope while keeping
their domain semantics inside the relevant sections. Every pack:

- identifies its official aggregate source and exact producer commit;
- replays deterministically to the recorded SHA-256;
- has `candidate_id: null`;
- keeps costs and fiscal effects unadmitted;
- reports `taxlane_admission_ready: false`; and
- denies savings, allocation, rate-change, and release authority.

This proves a candidate-free baseline intake class. It does not justify a Rust
adapter: plain JSON is already sufficient, and no pack can enter candidate
admission yet.

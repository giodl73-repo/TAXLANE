# CBO Major Outlay Category FY2026-FY2035 Context

Machine record:
`data/derived/breadth_benchmark_matrix/cbo_major_outlay_category_fy2032_2035_context.v1.draft.json`.

This packet extracts official CBO February 2026 open-data category context for
FY2026-FY2035 from the already-custodied ten-year budget CSV. It adds major
category context for defense, Social Security, Medicare, Medicaid, income
security, SNAP, family support, child nutrition, veterans, agriculture,
transportation-related expired-authority rows, higher education, and
administration of justice.

## Boundary

This is CBO FY2026-FY2035 major outlay-category context only. It is not an OMB
17-row ledger, not a Taxlane lane baseline, not a policy scenario, not
outcome-floor evidence, not solver input, not a rate calculation, not a savings
estimate, and not a balanced-budget claim.

The values reduce source-context gaps for several lanes, but the OMB 17-row
FY2032-FY2035 lane ledger, component paths, fund treatment, scenario packs,
floor values, transition models, solver mapping, and receipt/rate bridges remain
blocked.

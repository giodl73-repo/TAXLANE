# CBO Open-Data FY2032-FY2035 Current-Law Extension Context

Machine record:
`data/derived/breadth_benchmark_matrix/cbo_open_data_fy2032_2035_current_law_extension_context.v1.draft.json`.

This packet captures official CBO open-data CSVs for February 2026 budget,
revenue, and trust-fund projections. It fills real FY2032-FY2035 context for
top-line outlays, revenues, deficits, net interest, debt held by the public, and
selected trust-fund balances.

## What It Adds

- CBO top-line context for FY2032-FY2035: total outlays, total revenues,
  deficits, primary deficits, net-interest outlays, debt held by the public, and
  average interest rates.
- CBO revenue-detail context for FY2032-FY2035: individual income, payroll,
  corporate income, excise, customs, estate and gift, Federal Reserve, and
  miscellaneous fees.
- CBO trust-fund balance context for FY2032-FY2035: Highway, Airport and
  Airway, Medicare HI, OASI, and DI.

## Boundary

This is CBO FY2032-FY2035 current-law extension context only. It is not an OMB
17-row ledger, not a lane-level baseline, not trust-fund income/outgo
reconciliation, not a receipt/rate bridge, not solver input, not a rate
calculation, not a savings estimate, and not a balanced-budget claim.

The OMB FY2027 PBD 17-row context remains reconciled through FY2031 only. The
CBO FY2032-FY2035 values cannot be allocated into the OMB lane row map until a
separate reconciliation model is built and validated.

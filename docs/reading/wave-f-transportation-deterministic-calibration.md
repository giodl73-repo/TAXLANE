# Wave F Transportation Deterministic Calibration

Machine record:
`data/derived/breadth_benchmark_matrix/wave_f_transportation_deterministic_calibration.v1.draft.json`.

Wave F is complete as a deterministic transportation simulator calibration.
The FY2025-FY2035 fixture runs baseline, modernization, and stress paths with no
optimization; checks primary-outlay, net-cash, fund-balance, debt, interest,
reserve, and rounding interfaces; and proves that incomplete outcome floors
block a modeled productivity reduction from becoming a lower target cost or
rate effect.

All values are synthetic calibration units. This is dry-run-ready, but it is
not substantive-solver-ready, not rate-ready, not public-card-ready, not
savings-ready, and not balanced-budget-ready. It publishes no official fiscal
path, real reform score, target cost, assigned-base rate, or policy claim.

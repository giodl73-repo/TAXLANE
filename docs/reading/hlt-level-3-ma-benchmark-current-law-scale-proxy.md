# HLT Level-3 Medicare Advantage benchmark scale proxy

CBO's official option reduces outlays by $489 billion over FY2027-FY2034. A
year-matched scale sensitivity against the February 2026 Medicare path produces
$497.044 billion, averaging $62.131 billion annually.

This is not a CBO rescore. The old denominator is February 2024 net Medicare
outlays rather than the exact June 2024 option baseline, and the old and current
Medicare perimeters are not proven identical. The proxy is therefore useful for
package sizing, but it cannot enter the package until the beneficiary floors pass.

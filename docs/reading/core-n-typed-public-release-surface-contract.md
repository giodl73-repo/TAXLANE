# CORE-N typed public-release surface contract

CORE-N resolves the release-shape mismatch exposed by TRN Level 2. The legacy
rate-card contract requires rate-oriented fields, while H.R. 2247 has only a
candidate explanation and official incremental cost. CORE-N therefore makes
the public surface explicit before release eligibility is assessed.

Five surfaces are implemented: cost note, rate card, savings result,
non-additive integrity-overlay report, and endogenous fiscal-effect report.
Each remains bound to CORE-M's admitted outputs and applicable gates.

CORE-N does not publish a lane result. It prevents one surface from fabricating
the output of another.

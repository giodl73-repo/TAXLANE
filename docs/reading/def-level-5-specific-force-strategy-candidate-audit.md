# DEF Level 5 specific-force-strategy candidate audit

The audit selects CBO's proportional active-force reduction concept, which
preserves reserve units, as a concrete strategy to examine. That is a material
improvement over an unspecified topline reduction.

It is not yet an executable FY2026 package. The strategy predates the current
FYDP, CBO has not scored this selected implementation against the 2026
baseline, and current readiness, transition, procurement, munitions,
industrial-base, allied, and regional allocations are missing. The $959
billion topline score therefore remains an envelope, and admitted savings stay
at zero.

# Social Security old-age poverty context bridge

This packet explains
`data/derived/breadth_benchmark_matrix/social_security_old_age_poverty_context_bridge.v1.draft.json`.

Pulse 207 reuses the already source-custodied OECD old-age relative-poverty
panel for the Social Security lane. The source is
`SRC-OECD-IDD-AGE-POVERTY-PANELS`; the old-age raw file is
`data/raw/oecd/SRC-OECD-IDD-AGE-POVERTY-PANELS/2026-07-15/oecd-idd-old-age-poverty-2020-2024.csv`,
with 5,061 bytes and SHA-256
`910f741388bfa1c35cb9b68ac1588b6d51f08b016555a4209b784a905fb5e351`.

The context value carried forward for the United States is 22.874 percent in
2023 for people over 65 living in households below 50 percent of national
median equivalised disposable income. That is international old-age
relative-poverty context only. It is not an absolute deprivation threshold and
does not identify pension-policy causality by itself.

This bridge does not close the domestic old-age poverty floor gate. It leaves
domestic old-age poverty or near-poverty custody, income-unit and equivalence
scale review, benefit adequacy context, threshold rationale, policy and stress
values, and pass/fail evidence open.

This bridge is not domestic old-age poverty custody, not near-poverty context,
not an income-unit boundary, not threshold rationale, not old-age poverty floor
values, not benefit-adequacy floor values, not policy values, not stress values,
not pass/fail findings, not target-cost selection, not gross savings, not net
savings, not solver input, not rate calculation, not a public rate card, not a
department-cut instruction, not a technology-savings claim, and not a
balanced-budget claim.

Short validator phrases: international old-age relative-poverty context only;
not domestic old-age poverty custody; not solver input; not a balanced-budget
claim.

Compact validator phrase: not a balanced-budget claim.

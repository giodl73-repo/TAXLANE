# Lane E bounded selection and solver gate contract

TRN-E established the reusable rule for stage E: finish input classification
and selection, run the integrated solver only if a candidate and its inputs are
ready, and close under role review. A reviewed “no candidate” decision is a
bounded E result, not a solver result.

The same five-package contract now governs all fifteen tracks. Bounded E keeps
F, rates, savings, distribution results, public cards, and full-coverage claims
blocked. PAY and REV remain non-additive overlays; NET remains endogenous.

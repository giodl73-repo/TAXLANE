# Cost-Down Evidence Queue

## Purpose

This packet turns the cost-down source packets into a first-pass extraction
queue. It tells implementers what data to lock next before any savings,
performance, waste, or reform-benefit claim can be made.

Machine rows:
`data/derived/efficiency_pressure/cost_down_evidence_queue.fy2025.v1.draft.jsonl`.

## First-Pass Extracts

| Pressure surface | First extraction step |
|---|---|
| Health and Medicare price discipline | CMS/HHS service-level price, utilization, expenditure, and quality source inventory. |
| Health and Medicare administrative simplification | Claims, denials, appeals, authorization, rework, and integrity-control workflow inventory. |
| Debt interest primary balance | CBO/OMB deficit, debt, GDP, and net-interest baseline inventory with projection labels. |
| Debt maturity risk | Treasury debt-stock and average-rate extracts with query date and security-class basis. |
| Defense procurement control | GAO weapon-system program table inventory tied to program cost, schedule, and leading-practice indicators. |
| Defense audit-control closure | DoD OIG finding inventory with corrective-action status and mission/readiness floor. |
| Disaster mitigation | FEMA mitigation and declaration inventory linked by hazard, geography, project, and benefit-cost evidence status. |
| Disaster supplemental tracking | OMB, Treasury, USAspending, and FEMA event-to-account source inventory. |
| Payment integrity eligibility accuracy | PaymentAccuracy.gov program inventory with improper-payment rate, amount, root cause, target, and corrective-action fields. |
| Payment integrity claims timeliness | SSA and VA claims-processing inventory with processing time, backlog, accuracy, appeal, and access indicators. |

## Use Rule

Use this as an implementation queue only. Every row remains blocked for public
claims and savings estimates until query-locked extracts, outcome floors, and a
reviewed scoring method exist.

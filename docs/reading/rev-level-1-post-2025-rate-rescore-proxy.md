# REV Level-1 post-2025 rate-rescore proxy

The rate spine now has a post-2025-law numerical proxy. Taxlane annualizes the
CBO/JCT FY2025 partial-year one-point option and scales it by the change from
FY2025 actual to CBO's post-law FY2026 individual-income receipts. The result is
about $113.668 billion per uniform percentage-point increase.

For primary balance with $500 billion of annual spending correction, the proxy
produces a 2.760-point uplift: 12.760, 14.760, 24.760, 26.760, 34.760, 37.760,
and 39.760 percent. Raising only the top four brackets requires about 10.073
points under the same linear proxy.

Those schedules are numerical and reproducible, but not formal scores. Large
rate changes are nonlinear, and distribution, avoidance, timing, compliance,
administration, and macroeconomic response remain open.

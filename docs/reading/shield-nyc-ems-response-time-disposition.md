# SHIELD adds local EMS response components—not adequacy or savings

Taxlane replayed SHIELD's bounded calendar-2025 FDNY EMS dispatch baseline.
Of 1,612,273 incidents, 1,510,191 have a valid response time (93.67%). The
27,540 severity-1 records average 421.713 seconds from incident creation to the
first unit on scene and 372.592 seconds from first-unit assignment to scene.
Severity-1 borough mean response times range from 388.215 to 456.609 seconds.

This is real local operational context, backed by five exact aggregate API
response hashes and the official data dictionary. No incident rows or specific
locations are stored. Dispatch severity reflects caller information used for
resource allocation; it is not the patient's actual condition.

Arithmetic means do not reveal percentiles or tail performance. The evidence
does not supply an accepted target, scene-to-hospital time, compatible
population rates, outcomes, or a causal explanation for borough differences.
It therefore cannot establish service adequacy, inequity, an intervention, or
fiscal value.

Taxlane admits the response-component context but no candidate effect or
savings. HLT does not reopen. The remaining target stays **$813.727B**, and
both analytical rate schedules remain unchanged.

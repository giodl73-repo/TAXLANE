# HLT next Level A site-neutral evidence closure

HLT Level A is complete as a precise current-law reblock. CMS's CY2026 OPPS
rule extended site-neutral payment to drug administration in excepted
off-campus departments and estimated $220 million in Medicare savings plus $70
million in lower beneficiary coinsurance. It did not implement the selected
imaging option. The same rule also applies a separate 0.5 percent non-drug OPPS
offset, which changes the base against which the December 2024 CBO imaging
option would need to be rescored.

CBO's imaging option and annual score remain valid vintage-bounded evidence.
CMS and MedPAC add general payment, access, rural-exception, and quality
context, but they do not supply imaging-specific access, safety-net, diagnostic
timeliness, behavior, distribution, or current-law overlap results. The option
therefore remains unadmitted at zero FY2026 savings.

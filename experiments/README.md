# TAXLANE Experiments

Experiments test alternative fiscal institutions without promoting them as
policy recommendations or forecasts.

## Showcase Experiment Path

Before using an experiment in a demo, read
`docs/reading/taxlane-showcase-readiness-summary.md`. Experiments are separate
from the current showable source-custody/readiness guardrail; they are not
solver outputs, rate calculations, savings estimates, public rate cards,
department-cut instructions, technology-savings claims, or balanced-budget
plans.

Each experiment should contain:

- a versioned configuration and explicit assumptions;
- a reproducible runner with a fixed seed;
- machine-readable and reader-facing output;
- comparison rules and invariants; and
- a boundary note separating simulation results from observed public opinion.

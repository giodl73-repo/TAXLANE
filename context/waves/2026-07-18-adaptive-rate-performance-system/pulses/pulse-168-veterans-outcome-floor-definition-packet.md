# Pulse 168 — Veterans outcome floor definition packet

Pulse 168 extends the outcome-floor definition packet pattern to the veterans
lane.

The packet defines the five mandatory floor classes and veterans floor concepts:
earned eligibility, health access, claims timeliness, housing/employment
outcomes, and eligible-cohort/service-package feasibility.

No threshold value, observed value, pass/fail result, eligible cohort model,
service package model, statutory continuity finding, federal score, target cost,
savings estimate, solver input, department-cut instruction, technology-savings
claim, or balanced-budget claim is populated. Missing values remain null and
blocked gates remain false.

# Pulse 103 — Reserve parameter readiness gate

Pulse 103 adds
`data/derived/breadth_benchmark_matrix/reserve_parameter_readiness_gate.v1.draft.json`.

The gate names the reserve parameter choices that remain required before any
deterministic solver or public balanced-rate output may use reserve accounting:
contribution formula, withdrawal rule, balance series, cap formula, emergency
override threshold, emergency deferral cap, future-year payback schedule,
rounding residual line, source vintage binding, and role review.

No numeric reserve parameter is selected. Every parameter value remains null,
every gate status remains false, and all solver, rate, savings, waste, fraud,
technology, department-cut, tax-proposal, target-cost, public-rate-card, and
balanced-budget claims remain blocked.

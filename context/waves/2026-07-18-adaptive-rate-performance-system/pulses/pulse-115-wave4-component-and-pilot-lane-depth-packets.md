# Pulse 115 — Wave 4 component-and-pilot lane-depth packets

Wave 4 adds integrated public-explainability scaffolds for:

- Agriculture
- International affairs
- Transportation/infrastructure

The pulse uses existing local depth cards and transportation pilot artifacts.
It does not contact anyone, submit any external request, capture new source
bytes, select target costs, calculate rates, run the solver, estimate savings,
identify waste or fraud, direct department cuts, claim technology savings, or
claim a balanced budget.

Transportation remains the deepest pilot lane, but it is still incomplete:
FY2032-FY2035 federal rows, annual trust-fund values, federal/state/local
translation, floor thresholds, and floor pass reports are still missing.

Validation adds a focused Rust test that verifies the Wave 4 lane set, context
figures, null missing values, blocked claims, and required public warning
phrases.

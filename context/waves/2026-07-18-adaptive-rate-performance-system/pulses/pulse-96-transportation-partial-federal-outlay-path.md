# Pulse 96 — Transportation Partial Federal Outlay Path

## Scope

Add the already-local OMB Public Budget Database partial transportation federal
net-outlay path for FY2025-FY2031.

## Boundary

This pulse does not complete the FY2025-FY2035 baseline. FY2032-FY2035 remain
missing/null because they are not available in the local OMB PBD outlays
workbook. No interpolation is used.

## Acceptance coverage

- Records local raw OMB PBD outlays file, byte count, and SHA-256.
- States no new external request was submitted.
- Converts workbook thousands to millions.
- Reconciles every annual component sum to total.
- Confirms FY2025 equals the prior 145,320 million anchor.
- Keeps full baseline, trust-fund reconciliation, simulator, target-cost, rate,
  savings, and balanced-budget claims blocked.

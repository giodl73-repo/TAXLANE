# Pulse 137 — Receipt-base official source capture

Pulse 137 captures official public source files for IRS individual-income base
context, CMS Medicare HI taxable-payroll context, and FHWA transportation
highway-user receipt/legal-rate context.

The pulse extracts guarded context values only. It does not publish assigned
receipt bases, rates, solver inputs, public rate cards, tax proposals, savings,
waste/fraud findings, technology-savings claims, or balanced-budget claims.

SSA OASDI Trustees raw custody remains blocked because direct public download
attempts returned HTTP 403 from the official site in this environment. No FOIA
request, records request, form, email, phone call, or agency/person contact was
submitted.

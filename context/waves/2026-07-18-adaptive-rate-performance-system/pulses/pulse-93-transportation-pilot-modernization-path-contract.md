# Pulse 93 — Transportation Pilot Modernization Path Contract

## Scope

Create the modernization path contract for the selected transportation asset
maintenance and safety pilot.

## Artifacts

- `data/derived/breadth_benchmark_matrix/transportation_pilot_modernization_path_contract.v1.draft.json`
- `data/derived/breadth_benchmark_matrix/transportation_pilot_modernization_path_contract.schema.md`
- `docs/reading/transportation-pilot-modernization-path-contract.md`

## Boundary

This pulse creates a modernization contract, not a modernization result,
technology-savings claim, productivity finding, simulator run, target-cost
selection, rate calculation, public rate card, savings estimate, waste finding,
fraud finding, department-cut instruction, stress path, solver result, or
balanced-budget claim.

## Acceptance coverage

- Treats technology as a transition path, not an automatic cut.
- Blocks productivity credit until same-service-or-better, floor passes,
  transition costs, implementation/admin costs, monitoring/enforcement costs,
  and measured net effect exist.
- Names asset inventory/condition data, project delivery/permitting controls,
  predictive maintenance/operations, and safety targeting/network design
  segments.
- Keeps all effect values null, productivity credit false, and modernization
  records empty.
- Requires behavior/procurement/workforce/service-level fields for future
  rows.
- Requires stress later to be an adverse realization of the same policy, not an
  aggressive price reduction.
- Leaves blocked gates false, outputs null, and public claim booleans false.

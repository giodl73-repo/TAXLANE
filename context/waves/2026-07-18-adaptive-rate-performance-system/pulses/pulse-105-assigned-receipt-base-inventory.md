# Pulse 105 — Assigned receipt-base inventory

Pulse 105 adds
`data/derived/breadth_benchmark_matrix/assigned_receipt_base_inventory.v1.draft.json`.

The inventory lists candidate receipt bases and the required fields that must be
closed before any statutory or effective rate can be calculated: matched year,
legal perimeter, economic perimeter, baseline amount, elasticity,
avoidance/compliance, burden, distribution, tax interactions, current-law yield,
and reform yield.

Every base value remains null and every base remains not ready. No solver, rate,
public-card, tax-proposal, target-cost, savings, waste, fraud, technology,
department-cut, or balanced-budget claim is opened.

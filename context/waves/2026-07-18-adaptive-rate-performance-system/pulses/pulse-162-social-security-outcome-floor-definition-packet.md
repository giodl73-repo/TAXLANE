# Pulse 162 — Social Security outcome floor definition packet

Pulse 162 extends the outcome-floor definition packet pattern to the Social
Security lane.

The packet defines the five mandatory floor classes and the lane-specific Social
Security floor concepts: replacement adequacy, old-age poverty,
disability/survivor protection, trust-fund continuity, and administration and
transition feasibility.

No threshold value, observed value, pass/fail result, demographic score,
trust-fund solvency score, target cost, federal effect, savings estimate,
assigned-base rate, solver input, department-cut instruction,
technology-savings claim, or balanced-budget claim is populated. Missing values
remain null and blocked gates remain false.

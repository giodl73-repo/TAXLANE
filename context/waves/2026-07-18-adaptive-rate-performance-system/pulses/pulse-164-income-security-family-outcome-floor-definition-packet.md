# Pulse 164 — Income-security/family outcome floor definition packet

Pulse 164 extends the outcome-floor definition packet pattern to the
income-security/family lane.

The packet defines the five mandatory floor classes and lane-specific floor
concepts: child poverty, material hardship, formal childcare access,
work/care transition, and benefit-package/take-up delivery feasibility.

No threshold value, observed value, pass/fail result, benefit-package model,
take-up model, federal score, target cost, savings estimate, solver input,
department-cut instruction, technology-savings claim, or balanced-budget claim
is populated. Missing values remain null and blocked gates remain false.

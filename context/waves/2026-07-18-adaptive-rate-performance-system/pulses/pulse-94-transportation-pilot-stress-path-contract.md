# Pulse 94 — Transportation Pilot Stress Path Contract

## Scope

Create the stress path contract for the selected transportation asset
maintenance and safety pilot.

## Boundary

This pulse creates a stress contract, not a stress result, aggressive cut,
simulator run, target-cost selection, rate calculation, savings estimate, waste
finding, fraud finding, technology-savings claim, department-cut instruction,
solver result, or balanced-budget claim.

## Acceptance coverage

- Defines stress as an adverse realization of the same policy.
- Blocks using a harsher/aggressive cut as stress.
- Requires weaker modernization effect, higher implementation cost, higher
  utilization/volume, access-quality-equity remediation, weaker fund context,
  and higher interest context dimensions.
- Keeps all stress values null and stress records empty.
- Leaves blocked gates false, outputs null, and public claim booleans false.

# Pulse 82 — Adaptive rate system contract

Branch: `agent/pulse-82-adaptive-rate-system-contract`

Pulse 82 creates the first machine-readable contract for the adaptive rate and
performance phase. It defines the annual update lifecycle, separates rate
calculation from rate publication, preserves denominator definitions, requires
assigned-base fields, and keeps all rate and public-claim outputs blocked.

Created:

- `data/derived/breadth_benchmark_matrix/adaptive_rate_system_contract.v1.draft.json`
- `data/derived/breadth_benchmark_matrix/adaptive_rate_system_contract.schema.md`
- `docs/reading/adaptive-rate-system-contract.md`

Validation intent:

- rate calculation and publication remain separate;
- all-receipt and residual-general-fund denominator definitions remain distinct;
- assigned-base requirements remain missing/null;
- rate outputs remain null;
- all public claim booleans remain false.

No external request was submitted and no agency or person was contacted.

# Pulse 69: International Comparator Target Rubric

## Result

- Defines the peer median and interquartile range as the default description of
  a typical industrialized peer.
- Permits the favorable quartile as an attainable-ambition scenario only after
  directionality, outcomes, floors, transferability, and stability pass.
- Defines sustained high performers as policy examples to study, not automatic
  numeric targets.
- Blocks P85 on the current core panel and requires 20 peers, 80 percent
  coverage, three periods, and sensitivity analysis before stretch use.
- Makes the best observed country a diagnostic case only.
- Separates broad, display, structural-transfer, outcome-qualified, and policy-
  commitment reference classes.
- Assigns a benchmark treatment to all 15 lanes without opening any existing
  ranking, efficiency, fraud, or savings gate.

## Decision

```text
peer median = typical
favorable quartile = conditional ambition
sustained leader = example to study
best or P85 != automatic target
country gap != causal savings
```

Apply the rubric metric by metric. Existing country panels remain descriptive
until each statistic records its eligible universe, exclusions, N, coverage,
directionality, period, quantile method, floor tests, and sensitivity result.

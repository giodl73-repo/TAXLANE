Restore complete source without Git

Use Python 3.11 or later. Inspect and trust the receiver and its original grant texts before running it. Unpack the receiver separately from the archive and your new source directory. Verification runs no downloaded source code, installs no tools, and preserves existing destinations.

python -I -S -B receiver/tools/receive-source.py --archive downloads/source.tar.xz --sha256 @@SOURCE_SHA@@ --output new-TAXLANE --protect new-empty-target

The receiver verifies the trusted archive hash, bounded container, every path/file/mode, original Git commit/tree and complete inventory. Use a new destination outside the download, helper and compiled-target directories. Full-source bounds are 256,000,000 packed bytes, 512,000,000 decoded tar bytes and 6,000 original files. Allow several GB of available RAM for bounded in-memory verification, plus disk space for source, dependencies and compiled outputs. Windows retains original executable modes in the manifest; POSIX disk modes are checked where supported.

Build the same Rust-powered runtime

After trusting the restored source, install the declared external prerequisites: Rust 1.95.0, its wasm32-unknown-unknown target, wasm-bindgen 0.2.127 and Python. The complete original Cargo.lock and dependency archives are included. Rust package restoration and compilation use owned offline inputs; no Git checkout or default Cargo package cache is required.

cd new-TAXLANE
python -B tools/build-pages.py --inputs ../new-rust-inputs --cargo-home ../new-cargo-home --target ../new-empty-target

Use new input/home folders or an existing verified pair, and an initially absent compiled target for an independent rebuild. Outputs are dist/TAXLANE for the runtime and dist/source-artifacts for regenerated complete source/receiver/grant artifacts. The builder rejects changed source, unexpected dependency paths and output overlaps. Compare every output with its manifest; the runtime stays below 5 MB and the full source is measured separately.

For native/browser controls and an independent full replay, follow docs/self-service-delivery.md in the snapshot. Node, pinned Playwright/npm packages and browser binaries are additional test prerequisites. Optional research-model tools and data-admission work are separate; rebuilding this software does not regenerate or admit the FY2026 research results.

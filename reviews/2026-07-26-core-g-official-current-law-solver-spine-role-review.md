# Role Review: CORE-G Official Current-Law Solver Spine

## Decision

Approved as the official current-law federal topline spine and as the shared
CORE prerequisite for starting `TRN-A`.

| Role | Result | Finding |
|---|---|---|
| T-1 Taxpayer Advocate | Pass with boundary | No rate, payer allocation, or burden result is created. |
| T-2 Budget Accountant | Pass | All outlay, deficit-component, financing, and debt identities recompute; the FY2025 timing residual is explicit. |
| T-3 Source Custodian | Pass | Both CBO raw CSVs have local custody, metadata, retrieval dates, byte counts, hashes, vintage, and variable mappings. |
| T-4 Public Goods Steward | Pass with boundary | Federal toplines are not treated as lane or service-package allocations. |
| T-5 Program Beneficiary | Pass with boundary | No baseline value is treated as a target cost or evidence that a reform protects services. |
| T-6 Compliance Burden | Pass with boundary | No administration, compliance, incidence, or behavioral estimate is inferred. |
| T-7 Fiscal Sustainability | Pass | Net interest remains separately identified and debt rollforwards include explicit financing and timing. |
| T-8 Reform Skeptic | Pass | Current-law projections are not relabeled as policy scores or recommendations. |

## Downstream boundary

CORE-G unlocks discovery and implementation of `TRN-A`. CORE-H, named funds,
reserves, reform effects, target costs, rates, savings, and publication remain
open.

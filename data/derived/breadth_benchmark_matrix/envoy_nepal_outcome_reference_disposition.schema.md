# ENVOY Nepal outcome-reference disposition schema

## Product question

Do observed Nepal national-system outcomes identify an attributable MCC
Compact effect that can enter Taxlane?

## Contract

`producer` preserves the exact ENVOY commit, replay command, pack identity,
hash, feature count, and test count. `official_findings` preserves the selected
national observations. `attribution_assessment` tests compact specificity,
targets, exposure, counterfactual, evaluation, incidence, safeguards, and
matched costs before any candidate effect can be admitted.

## Invariants

- Temporal movement during implementation is not causal attribution.
- A national outcome is not a compact-specific outcome.
- Observed exports, supply, losses, revenue, recovery, or capacity are not U.S.
  fiscal savings.
- INT cannot reopen without an attributable bounded effect, applicable floors,
  delivery readiness, non-additive accounting, and a matched fiscal bridge.

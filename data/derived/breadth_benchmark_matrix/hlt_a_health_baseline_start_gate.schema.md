# HLT-A Health Baseline Start Gate Schema

HLT-A starts from completed CORE-G. It contains five ordered baseline/source
work packages. HLT-B requires both completed HLT-A and CORE-H; therefore HLT-B
remains blocked while HLT-A is open even though CORE-H is already complete.

HLT-A-01 through HLT-A-03 are complete. The baseline contains exact
FY2025-FY2031 rows and explicit FY2032-FY2035 nulls, while the financing
lineage keeps trust-fund, general-fund, premium, and state relationships
separate. HLT-A-04 and HLT-A-05 are complete, closing the bounded A-stage source
spine. HLT-B-01 account-mapping discovery is active while numeric horizon,
floor, reform, solver, rate, and savings outputs remain blocked.

# Repository corpus inventory snapshot

This operational record makes exact repository-scale claims reproducible. Each
count names its path and matching rule. The snapshot is valid only for its
stated worktree state and must be refreshed after corpus changes.

The inventory is supporting metadata, not evidence that a policy conclusion is
correct, useful, officially accepted, publicly adopted, or externally
validated. Website copy must lead with user-visible outcomes and keep these
counts subordinate.

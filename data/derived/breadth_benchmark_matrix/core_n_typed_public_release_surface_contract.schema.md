# CORE-N typed public-release surface contract schema

CORE-N separates five public surfaces: cost note, rate card, savings result,
integrity-overlay report, and endogenous-effect report. Every surface must match
one CORE-M candidate profile and contain its required typed output.

All applicable gates, role review, public-language review, and reproducible
release must pass. Reviewed non-applicability cannot create a missing result.
A cost note cannot be labeled a rate card; an overlay cannot be labeled savings;
and an endogenous effect cannot be presented as a direct cut.

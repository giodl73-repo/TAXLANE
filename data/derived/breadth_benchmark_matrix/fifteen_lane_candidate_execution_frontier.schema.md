# Fifteen-lane candidate execution-frontier schema

This record classifies exactly one current candidate or downstream function for
each of the 15 TAXLANE tracks. Every row must state execution class, strongest
evidence, decisive blocker, priority band, and admission disposition.

Priority favors evidence closure, not headline dollars. `A_advance_now`
requires an operating intervention and observed causal evidence. Active but
immature implementations remain `B_monitor_active`; unimplemented scored
options remain dependency or owner-evidence work. NET and REV remain downstream
functions and cannot be selected as primary spending reductions.

The frontier may select the next evidence target. It may not admit savings,
sum option envelopes, initiate an official request, change a solver or rate, or
authorize a public release.

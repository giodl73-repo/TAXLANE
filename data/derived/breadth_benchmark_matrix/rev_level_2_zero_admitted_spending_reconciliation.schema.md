# REV Level-2 zero-admitted-spending reconciliation schema

This record must reconcile the Level-1 guarded schedule to the admitted package
before preserving or replacing any rate result. A schedule conditioned on an
unadmitted spending correction is superseded for the active package.

Any replacement derived from the same linear proxy remains a sensitivity until
formal current-law scoring, timing, behavior, distribution, administration,
interactions, and macro gates pass.

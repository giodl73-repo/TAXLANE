# TRN-B Transportation Accounting Closure Schema

TRN-B closes only after all six work packages are complete, fourteen named-fund
rows and seven Function 400 crosswalk rows reconcile, both source-bridge
decisions are explicit, evidence-supported schedules are published, missing
values remain null, and eight-role review passes.

Closure is bounded to the admitted FY2025-FY2031 OMB ledger. It permits TRN-C
to start but does not assert a full-horizon lane solver path, reform score,
rate, savings estimate, or balanced-budget result.

# ENVOY Nepal Compact evaluation-readiness disposition schema

## Product question

Does current evaluation-procurement evidence make the Nepal Compact candidate
effect observable or change Taxlane's fiscal result?

## Contract

`producer_input` preserves the exact ENVOY commit, replay command, output hash,
candidate identity, dependency on the prior full pack, and denied authority.
`evaluation_readiness` preserves each project evaluation's status and value
band while representing absent design and result fields as null.

## Invariants

- A solicitation is evaluation readiness, not an award or completed result.
- A cancelled evaluation is not active evaluation coverage.
- Forecast value bands are not project costs, effects, or savings.
- Projected beneficiaries and ERRs are not observed outcomes.
- Effect review requires an independent, exposure-aligned, cohort-bounded
  design with local incidence and safeguard linkage.
- No candidate admission, savings, reopening, target change, or rate
  recomputation occurs.

# Fiscal-package OAS contribution-bridge schema

This record keeps primary spending correction, OASDI payroll-tax solvency, and
REV individual-income-tax effects on separate rails. It may compare official
scale, but it must not count a payroll-tax deficit effect as spending savings or
add an already-offset income-tax interaction to REV.

Unrescored solvency effects remain null and cannot revise the guarded rate.

# Eight-track two-level candidate catch-up schema

The artifact contains exactly VET, EDU, ISF, AGR, DIS, JUS, SEE, and INT. Each
row must complete Level 1 with a concrete source-identified candidate and Level
2 with a candidate-specific dependency and floor rerun. A headline budget
effect is an envelope, not an admitted contribution. Each row must state its
FY2026 admitted primary reduction and F-start decision; blocked portfolio
outputs remain null.

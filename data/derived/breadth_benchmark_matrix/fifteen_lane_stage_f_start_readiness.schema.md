# Fifteen-lane stage-F start readiness schema

The matrix contains exactly one row per canonical prefix and cites its E
evidence. Each row records E completion class, selection, solver, output-ready,
and F-start state. Current evidence contains fourteen bounded E rows and one
typed output-ready TRN row. TRN-F is complete only as a cost note containing
the candidate explanation and official incremental cost; the other fourteen F
starts remain blocked.
Special treatment is mandatory for PAY, REV, and NET.

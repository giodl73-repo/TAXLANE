# TRN Level-1 CORE lessons audit schema

This record separates lane-specific evidence work from shared interfaces exposed
by a real candidate. It must map CORE-G through CORE-L coverage, identify
reusable lessons, preserve unresolved TRN work, and keep every output null.

A proposed CORE wave is a discovery recommendation only. It must not be marked
started or complete until its own contract, implementation, tests, and role
review exist.

The central semantic rule is that candidate class controls applicable solver
and release requirements. A reviewed `not applicable` disposition may resolve
applicability, but it may not fabricate a value, pass/fail result, rate, or
savings estimate.

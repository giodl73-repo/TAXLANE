# HLT-B Health Accounting Start Gate Schema

HLT-B requires completed bounded HLT-A and CORE-H. Its first package mapped
health components to shared accounting roles while preserving trust-fund,
premium, state, private, and horizon boundaries. CORE-J and CORE-K are pinned,
HLT-B is complete, and HLT-C closed a bounded screen with no reform admitted.
This does not admit complete schedules, bases, rates,
solver input, reform, or HLT-C.

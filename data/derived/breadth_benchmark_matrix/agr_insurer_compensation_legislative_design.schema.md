# AGR insurer-compensation legislative-design schema

This artifact converts the closed administrative path into a bounded,
scoreable legislative design. It must contain four alternatives, exactly one
selected score specification, separate A&O and underwriting levers, an explicit
statutory amendment, a prospective transition, service floors, a scorekeeper
input contract, and an adaptive evaluation cycle.

The selected 12-percent parameter is an official-option precedent used to make
the design reproducible. It is not an asserted optimal return, a current market
finding, a current-law score, an admitted saving, or a rate instruction.

Every service floor must name a measure, trigger, and response. Unmeasured
floors fail closed. Gross reductions, implementation cost, behavioral and
service offsets, and net mandatory outlays remain separate.

The artifact may authorize a repo-only sensitivity model. It may not claim
enactment, make an official request, admit a candidate or spending reduction,
run the fiscal solver, or change a rate.

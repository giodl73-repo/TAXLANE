# Fifteen-track next two-level advancement wave schema

The wave must contain each canonical prefix exactly once. Every row must name
the current evidence, one Level A evidence-closure task, and one dependent
Level B admission or typed-output rerun. Starting the wave does not complete a
level, admit a candidate, produce a score, or change the planning rate.

PAY remains non-additive, REV remains a receipt instrument, NET remains
endogenous, conditional costs are not savings, and all blocked outputs remain
null until their own exit evidence exists.

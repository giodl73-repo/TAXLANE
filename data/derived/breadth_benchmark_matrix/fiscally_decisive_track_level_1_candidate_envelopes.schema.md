# Fiscally decisive track Level-1 candidate-envelope schema

This record advances HLT, OAS, PAY, NET, and DEF by selecting an official
candidate or, where selection would be misleading, a typed measurement or
endogenous dependency envelope. Every numeric value retains its source vintage,
units, timing, and admissibility boundary.

An official option is not automatically a current-law score. An improper-payment
estimate is not recoverable savings. Net interest is not a direct-cut candidate.

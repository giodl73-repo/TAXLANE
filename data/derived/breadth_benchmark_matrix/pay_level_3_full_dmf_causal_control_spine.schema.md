# PAY Level-3 full-DMF causal-control spine schema

This record may select a specific payment-integrity control and publish an
officially reported, cost-netted benefit only when the causal filter is stated.
It must preserve prevention, identification, recovery, program ownership,
cash disposition, and fiscal-period gaps as separate nulls.

Neither the government-wide improper-payment estimate nor the pilot net benefit
is package savings, a recurring score, or an additive lane contribution.

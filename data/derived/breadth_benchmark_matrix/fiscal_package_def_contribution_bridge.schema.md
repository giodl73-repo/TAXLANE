# Fiscal-package DEF contribution-bridge schema

This record compares the unchanged DEF option and HLT planning sensitivity with
the assumed annual spending correction used by REV. Mechanical and admitted
contributions must remain separate. An unallocated defense topline has a null
admitted contribution even when the official option has numeric timing.

The bridge may show the residual planning requirement; it may not rescore the
option, create savings, change the REV schedule, or claim budget balance.

# International Comparator Target Rubric

This artifact separates three decisions that prior `benchmark_type` fields can
otherwise blur:

1. Who is eligible to be compared?
2. Which statistic describes the comparison?
3. When can a descriptive reference become a scenario or target?

The default descriptive benchmark is the equal-country peer median with the
interquartile range. The United States is displayed but excluded from the peer
statistic. A structurally matched panel is a separately labeled sensitivity,
not a replacement chosen after viewing results.

The favorable quartile is a conditional attainable-ambition reference only
when directionality, outcomes, transferability, stability, and access/quality/
equity/adequacy floors pass. The best country is a case study, never a default
target. P85 requires at least 20 comparable peers and cannot be used on the
current core panel.

Country comparisons alone never establish causal efficiency, waste, fraud, or
recoverable savings.

# Wave G Official Current-Law Solver Spine Contract Schema

This schema governs
`wave_g_official_current_law_solver_spine_contract.v1.draft.json`.

## Wave definition

Wave G constructs and admits one official FY2025-FY2035 current-law federal
topline spine. It fixes the baseline horizon, source vintage, sign conventions,
financing residual, debt rollforward, and net-interest lineage required before
real reform deltas can enter a substantive solver.

Wave G is complete only when all eight completion gates are ready:

1. official raw-byte custody and field-level lineage;
2. exactly eleven populated fiscal years with no interpolation;
3. one FY2026-FY2035 projection vintage and an explicit FY2025 actual bridge;
4. exact topline and deficit-component reconciliation;
5. exact debt rollforward with explicit other financing/timing;
6. baseline net-interest lineage that preserves interest as endogenous;
7. eight-role boundary review; and
8. independent deterministic repository validation.

## Boundary

Wave G admits only the current-law federal topline spine. It does not admit
17-row or lane allocations beyond available official evidence, fund paths,
reserve choices, assigned receipt bases, real reforms, target costs, rates,
savings, or balanced-budget claims.

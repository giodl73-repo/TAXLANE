# TRN-E Integrated Candidate Solver Start Gate Schema

TRN-E starts only after bounded TRN-D closure. Its first package has reconciled
input readiness and CORE-J/CORE-K are pinned. Candidate selection closes with no
admissible target or financing source, so the run and sensitivity packages are
not required and TRN-E closes bounded. This does not admit a financing source, complete
floor set, candidate target cost, solver input, solver result, rate,
distribution result, savings, or TRN-F start.

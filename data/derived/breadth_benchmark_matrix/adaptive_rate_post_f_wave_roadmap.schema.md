# Adaptive Rate Post-F Wave Roadmap Schema

This schema governs `adaptive_rate_post_f_wave_roadmap.v1.draft.json`.
It preserves the Pulse 233 predecessor vocabulary. Pulse 234 supersedes its
generic stage names with the controlling CORE/TRN corpus plan; the predecessor
remains available for provenance.

## Required roadmap

The record must define exactly six dependency-ordered waves:

- G — official current-law solver spine;
- H — fund, reserve, transfer, offset, and endogenous-interest substrate;
- I — first real transportation reform scenario admission;
- J — matched receipt-base, incidence, distribution, behavior, and administration bridge;
- K — integrated internal candidate solver and rate calculation; and
- L — first public pilot rate card and closure review.

Each wave requires an objective, dependencies, acceptance gates, newly allowed
outputs, prohibited outputs, and a mapped completion state. The dependency
chain is `G -> H -> I -> J -> K -> L`. The current legacy mapping records G,
H, and I complete as CORE-G, CORE-H, and TRN-C, with J active as TRN-D.

## Coverage and boundaries

All ten post-F blockers must map to a primary closure wave. One pilot never
implies all-lane readiness. Only Wave L may admit a public pilot card, and only
after every prior dependency and publication gate passes. Statutory enactment,
all-lane rates, unsupported savings, waste/fraud inference, and a portfolio
balanced-budget claim remain outside this roadmap.

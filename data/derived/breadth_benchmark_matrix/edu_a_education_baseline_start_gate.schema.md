# EDU-A Education Baseline Start Gate Schema

EDU-A starts from completed CORE-G. It contains five ordered baseline/source
work packages. EDU-B requires both completed EDU-A and CORE-H; therefore EDU-B
remains blocked while EDU-A is open even though CORE-H is already complete.

EDU-A-01 through EDU-A-03 are complete. The baseline contains exact
FY2025-FY2031 rows and explicit FY2032-FY2035 nulls, while the financing
lineage preserves appropriations, grants, credit-account signs, offsets, and
state/local non-additivity. EDU-A-04 and EDU-A-05 are complete, closing the
bounded A-stage source spine. EDU-B-01 account-mapping discovery is active while
numeric horizon, translation, floor, reform, solver, rate, and savings outputs
remain blocked.

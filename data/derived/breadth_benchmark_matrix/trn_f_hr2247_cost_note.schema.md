# TRN-F H.R. 2247 cost-note schema

The TRN-F record must use the CORE-N `cost_note` surface and contain exactly a
candidate explanation plus the official incremental cost. Legislative status,
enactment and appropriation conditions, horizon, source identity, evidence
grade, and public claim status are mandatory.

All source, role, public-language, and reproducibility checks must pass. Rate,
savings, lower-cost, named-fund, distribution, endorsement, and balanced-budget
outputs remain null or false.

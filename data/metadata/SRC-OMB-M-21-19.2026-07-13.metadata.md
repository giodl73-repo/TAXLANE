## Evidence locator

Printed page 17 (PDF file page 18; zero-based viewer index 17) requires
statistically valid estimates to produce point estimates and confidence
interval estimates. Printed page 18 (PDF file page 19; zero-based viewer index
18) directs agencies to upload the Sampling and Estimation Methodology Plan and
OMB checklist to the agency's secure MAX page.

## Boundary

This governmentwide control establishes what the plan must support and where it
is submitted. It does not disclose FCIC's plan, estimator, weights, variance
method, or exclusion rules. Secure MAX submission is not public reproducibility.
